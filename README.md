# Art-Gallery-Management-System
Art Gallery Management System for managing artworks, artists, exhibitions, and inventory efficiently.


 📌 Project Overview

The **Art Gallery Management System** is a web-based application designed to manage artwork inventory, artist information, exhibitions, and gallery operations efficiently.

The system provides a centralized platform for organizing and managing important gallery-related information, reducing manual record management and improving operational efficiency.

🎯 Objectives

* Manage artwork information efficiently.
* Maintain artist records.
* Manage exhibitions and artwork displays.
* Track artwork inventory.
* Store and manage gallery information in a database.
* Reduce manual record-keeping.
* Provide an organized system for gallery operations.

🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python
* **Database:** MySQL

✨ Key Features

👤 Artist Management

* Add artist information
* Update artist details
* View artist records
* Manage artist-related artwork information

🎨 Artwork Management

* Add new artwork
* Update artwork details
* View artwork information
* Manage artwork inventory
* Track artwork availability

 🖼️ Exhibition Management

* Create and manage exhibitions
* Add artworks to exhibitions
* Maintain exhibition information
* View exhibition details

📦 Inventory Management

* Maintain artwork inventory
* Track artwork availability
* Organize artwork records
* Update inventory information

 🗄️ Database Management

MySQL is used to store and manage project data, including artist, artwork, exhibition, and inventory information.

 ⚙️ System Workflow

The general workflow of the system is:

**User → Web Interface → Python Application → MySQL Database → Data Management**

The user interacts with the web interface to manage gallery information. Python handles the application logic, while MySQL stores and retrieves the required data.

🏗️ Main Modules

1. **Login / User Management**
2. **Artist Management**
3. **Artwork Management**
4. **Exhibition Management**
5. **Inventory Management**
6. **Database Management**
7. **Gallery Operations**
 🗃️ Database Components

The database can contain tables such as:

* Users
* Artists
* Artworks
* Exhibitions
* Exhibition_Artworks
* Inventory
* Gallery
